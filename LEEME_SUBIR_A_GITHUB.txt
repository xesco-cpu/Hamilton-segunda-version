GUÍA HAMILTON-T1 · GitHub Pages · versión offline SW 3.1.x

INSTRUCCIONES (Android o PC)
1) Extrae el ZIP en tu teléfono/ordenador.
2) En GitHub entra en el repositorio Hamilton-T1-manual.
3) En Code > Add file > Upload files, sube TODOS los archivos y la carpeta figuras_oficiales_31x.
   Asegura que index.html quede en la RAÍZ, NO dentro de HAMILTON_T1_GITHUB_LISTO.
4) Confirma con Commit changes en la rama main.
5) Settings > Pages > Build and deployment > Source: Deploy from a branch > main / (root) > Save.
6) Tras publicar: https://xesco-cpu.github.io/Hamilton-T1-manual/
7) En Android abre en Chrome, menú ... > Instalar aplicación / Añadir a pantalla de inicio.
8) ABRE LA APLICACIÓN UNA VEZ CON RED y comprueba que cargan todas las figuras.
9) Activa el modo avión y abre la app: los montajes, las tablas y las capturas siguen disponibles.
